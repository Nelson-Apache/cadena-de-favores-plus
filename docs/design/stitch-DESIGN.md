# Cadena de Favores+ — Design System (Web)
Plataforma web de ayuda comunitaria ante desastres en el Quindío, Colombia. Tono: cercano, sereno, confiable, cívico. Nada de estética corporativa azul; identidad cálida inspirada en el paisaje cafetero (petróleo profundo, arena, crema).

## Color
- Primary "Petróleo" #0F5563 — navegación, botones primarios, enlaces.
- Ink #13262B — textos principales y fondos oscuros (hero, footer).
- Background "Crema" #FAF7F2, superficies #FFFFFF, bordes #E6DFD3, arena #C9B89C / #EFE6D8.
- Tertiary "Lila" #7B5EA7 — reservado para VIVIENDAS SOLIDARIAS (ícono casa, sello "Arriendo solidario").
- Recursos "Red lista": azul pizarra #3B6FD8 (ícono cuadrado/escudo).
- Semáforo de estado (solo para necesidades, nunca decorativo): Sin ayuda #D64545, Ayuda en camino #E0A100, Atendida #2E9E5B.
- Prioridad: Alta (rojo sólido), Media (ámbar contorno), Baja (gris).

## Tipografía
- Titulares: Sora, peso 700, tracking ajustado, tamaños grandes en desktop (56–72px hero).
- Cuerpo: DM Sans 16px, interlineado 1.55.
- Números y métricas: DM Sans tabular.

## Forma y layout
- Radios 12px en tarjetas, 999px en chips y pills.
- Layout web desktop 1440px, contenedor 1200px, grid de 12 columnas; responsive a móvil.
- Sombras suaves y difusas, bordes finos de 1px. Mucho aire.
- Mapa como protagonista: panel lateral + mapa a pantalla completa (estilo Airbnb/Google Maps), no mapa pequeño.
- Barras de progreso redondeadas con el color del estado ("2 de 5 carpas").
- Sello "Arriendo solidario": badge circular estilo sello de tinta en lila.
- Íconos lineales (Material Symbols Rounded).
- Todo el contenido en español de Colombia.
